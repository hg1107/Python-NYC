# Four pillars of OOP
Encapsulation: keeping info safe and only letting it be changed or looked at in specific ways [data ko safe rakhna]
Polymorphism: one thing performing multiple tasks
Inheritence: one class inheriting some features of other class
Abstraction: Seeing only essential part and hiding complexity and rest of the process from user
